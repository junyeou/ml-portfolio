# ML & AI Portfolio

Hi, I'm Junye Ou. This repository is my learning journey and project portfolio in machine learning and artificial intelligence. Each topic below has hands-on projects, with a README explaining the problem, approach, results, and what I'd improve.

**Goal:** build real understanding of core ML/AI concepts by shipping projects, not just reading about them.

## Tech Stack

(PyTorch and others will be added as projects require them.)

## Getting Started

```bash
git clone https://github.com/junyeou/ml-portfolio.git
cd ml-portfolio
python -m venv .venv
.venv\Scripts\activate        # Windows (use: source .venv/bin/activate on Mac/Linux)
pip install -r requirements.txt
```
